# Chebaturkin Clear Copy

Скилл для редактуры и написания коммерческих текстов в ясном, тёплом и спокойном голосе Chebaturkin Studio.

Он помогает сохранить исходную мысль и характер автора, сделать предложение понятнее, назвать реальное действие и не потерять точные условия работы.

## Состав

- `SKILL.md` — основные правила и границы применения.
- `references/studio-guide.md` — голос студии, редакторские решения, примеры и порядок проверки.
- `agents/openai.yaml` — название и подсказка для интерфейса Codex.

## Установка

Скопируйте папку `chebaturkin-clear-copy` в каталог навыков Codex:

```text
~/.codex/skills/chebaturkin-clear-copy/
```

Вызовите скилл явно:

```text
Используй $chebaturkin-clear-copy, чтобы улучшить этот текст, сохранив мысль, характер и точные условия.
```

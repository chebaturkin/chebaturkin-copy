# Copy

скилл для простых, понятных текстов.

помогает написать пост, собрать текст страницы, ответить клиенту или объяснить действие в интерфейсе. при редактуре сохраняет мысль и голос автора, убирает пустые формулировки и делает главное понятнее.

[установка](#установка) · [как пользоваться](#как-пользоваться) · [что внутри](#что-внутри)

## как это работает

вы даёте задачу и материалы. Copy учитывает читателя, площадку и ваш голос, затем пишет или редактирует текст. если для точного ответа не хватает важного факта, уточняет его.

| было | стало |
| --- | --- |
| осуществляем проведение занятий по рисованию для детей от 7 до 10 лет | проводим занятия по рисованию для детей от 7 до 10 лет |
| в случае возникновения вопросов вы можете осуществить обращение к нам по электронной почте | если у вас есть вопросы, напишите нам на почту |

здесь меняется формулировка, а возраст детей и способ связи сохраняются. так же остаются на месте цены, сроки, ограничения и степень уверенности автора.

удачную фразу скилл может оставить. юмор, образность и живой ритм тоже могут быть частью хорошего текста.

## установка

### в Codex для всех ваших проектов

скопируйте репозиторий в личный каталог скиллов:

```bash
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/chebaturkin/chebaturkin-copy.git "$HOME/.agents/skills/copy"
```

после установки вызовите `$copy` в задании. если скилл не появился, перезапустите Codex.

### в один проект

выполните из корня нужного проекта:

```bash
mkdir -p .agents/skills
git clone https://github.com/chebaturkin/chebaturkin-copy.git .agents/skills/copy
```

выберите личную или проектную установку, чтобы один скилл не появлялся дважды. если папка `copy` уже существует, сначала проверьте, что в ней установлено: команды выше её не перезаписывают.

### обновление

для личной установки:

```bash
git -C "$HOME/.agents/skills/copy" pull --ff-only
```

для проектной установки замените путь на `.agents/skills/copy`.

<details>
<summary>если репозиторий уже скачан или вы используете другой агент</summary>

можно связать скачанную папку с каталогом скиллов. замените путь на свой:

```bash
mkdir -p "$HOME/.agents/skills"
ln -s /absolute/path/to/copy-repository "$HOME/.agents/skills/copy"
```

создавайте ссылку, если путь назначения ещё свободен. изменения исходной папки будут доступны без повторного копирования.

в агенте с поддержкой Agent Skills установите папку по его правилам. без такой поддержки передайте [SKILL.md](SKILL.md) и нужные справочники как инструкции. загрузка файлов зависит от среды.

## как пользоваться

для простой правки достаточно текста и задачи:

```text
используй $copy. отредактируй этот пост, сохрани мой юмор
и основную мысль. верни готовый текст: …
```

для нового текста добавьте известные факты:

```text
используй $copy. напиши письмо клиентам о переносе встречи.
новая дата — 18 ноября, время — 12:00 МСК.
обращение на «вы», тон спокойный.
```

если хотите понять правки:

```text
используй $copy. проверь текст формы и покажи «было → стало»
с короткой причиной. кнопка открывает черновик письма,
пользователь отправляет его сам: …
```

читатель, площадка, желаемый тон и ограничения помогают точнее попасть в задачу. для редактуры одной фразы полный бриф не нужен.

## ваш голос

Copy берёт голос из задания, правил проекта и исходного текста. можно писать от себя или команды, на «ты» или «вы», спокойно или с юмором. для официального письма сохраняется официальный тон, для рассказа — характер рассказчика.

если у вас есть отдельный профиль стиля, подключите его вместе с Copy. он уточнит интонацию и оформление; факты останутся в материалах проекта.

строчные начала на этой странице — оформление автора. сам скилл использует обычную орфографию, если вы не задали другой стиль.

## проверка на своих текстах

возьмите знакомый текст и задачу, для которой он написан. после редактуры проверьте, сохранились ли мысль, факты и характер автора, стало ли понятнее читателю.

результат зависит от модели и исходных материалов. встроенная проверка подтверждает структуру пакета; качество готового текста нужно оценивать отдельно.

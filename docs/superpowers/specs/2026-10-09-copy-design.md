# Copy: устройство универсального скилла

## Цель

Самостоятельный публичный пакет для написания и редактуры текстов разных авторов, проектов и форматов. Системное имя — `copy`, отображаемое — `Copy`.

## Решение

Общие редакторские принципы находятся в `SKILL.md`: сохранение мысли, фактов и голоса, работа с абстракциями, уместная структура. Голос конкретного автора подключается отдельным профилем и не становится универсальным правилом. Проектные факты берутся из исходников.

Рассмотрены единый пакет с настройками и два независимых пакета. Выбран второй подход: универсальный скилл не требует личного профиля; профиль может использоваться с другим редакторским инструментом. Общие принципы не дублируются в авторском профиле как обязательная зависимость.

## Файлы

`references/editing-guide.md` содержит условные рекомендации по форматам. `references/examples.md` показывает решения без привязки к бизнесу. README объясняет установку и применение. `agents/openai.yaml` согласован с новым именем. `evals/cases.md` проверяет различия голосов, форматов и границы фактов.

## Границы

Никаких личных привычек по умолчанию, бизнес-условий из старых примеров, обязательной продажи и принудительного сокращения. Неизвестные факты не восполняются выдумкой. Название удалённого репозитория и история Git не меняются автоматически при переименовании скилла.

## Проверка

Валидация manifest и YAML, существование относительных ссылок, отсутствие старого имени и бизнес-привязок в текущем пакете. Поведенческие задания дополняют структурную проверку. Результаты отделяются от ожиданий.
